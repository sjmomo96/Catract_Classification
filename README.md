# Confidence-Aware Referee Network (CARN) for Fundus Image-Based Cataract Detection

> Accepted at **IEEE Bangladesh Electrical, Computer and Information Technology Conference (BECITHCON), 2026** — 04-05 September 2026, Dhaka, Bangladesh.

---

This paper introduces CARN, a cataract detection framework that combines EfficientNet-B2 and DenseNet121, where a Gradient Boosting referee resolves
disagreements between the two models using confidence scores and physics-derived image features.
