# Confidence-Aware Referee Network (CARN) for Fundus Image-Based Cataract Detection

This paper introduces CARN, a cataract detection framework that combines
EfficientNet-B2 and DenseNet121, where a Gradient Boosting referee resolves
disagreements between the two models using confidence scores and physics-derived
image features. 

Accepted at **2026 IEEE BECITHCON**, Dhaka, Bangladesh.
